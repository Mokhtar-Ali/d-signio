# D-Signio

D-Signio is a Next.js website for a contract furniture, interior design, and styling studio serving hospitality, institutional, real estate, and residential projects.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project

- `src/app/page.tsx` renders the home page.
- `src/app/projects/page.tsx` renders the project portfolio.
- `src/components/layout/Header.tsx` contains the shared navigation and D-Signio logo.
- `src/data/` contains the project, partner, and business-line content.
